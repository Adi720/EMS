# EMS Seva — Quick start

EMS Seva manages **Calling Seva**: the Saints met at the EMS stall, the callers who phone them, and
each Sunday's **EMS Congregation** (shown as e.g. *EMS Congregation (1 Nov 2026)*).

## Which guide do I need?

| You are… | Read |
|---|---|
| A **caller** — you phone Saints before Sunday | [Caller manual](caller-user-manual.md) |
| A **coordinator** — you run Calling Seva | [Coordinator manual](coordinator-user-manual.md) |
| The **system administrator** — you install and look after the app | [System administrator guide](system-administrator-guide.md) |
| Want an overview of everything it does | [Feature catalogue](feature-catalogue.md) |

## The weekly routine in one table

| When | Who | What |
|---|---|---|
| Saturday morning | Coordinator | Dashboard → **Start calling for EMS Congregation (date)**, then **Share reminder on WhatsApp** |
| Saturday | Callers | **My calls** → **📞 Call** → tap **Yes**, **Not Possible**, **Will Try** or **Call Not Connected** |
| During the day | Coordinator | Dashboard shows progress for every caller |
| After Sunday | Coordinator | Congregation page → **Export** results if needed; next Saturday's click closes the week |

## Getting started (once)

1. **System administrator:** install the app, create the coordinators
   ([guide](system-administrator-guide.md)).
2. **Coordinator:** **Import** the EMS workbook — it brings in the Saints and their callers and can
   create the callers' logins; share each login privately ([manual, section 9](coordinator-user-manual.md#9-import-from-excel)).
3. **Coordinator:** check **Assignments** — every caller has their Saints, none without a caller.
4. On Saturday: **Start calling**.

## Good to know
- Callers only ever see their own Saints.
- **Will Try** is never counted as a Yes; the latest result for each call counts.
- Saints added by mistake can be deleted (only if they have no call results); otherwise inactive
  Saints, deactivated callers and past weeks keep their history.
- New Saints stay **New** for 6 months after the stall date, then become **Active** by themselves.
- Callers can **Raise Request** (Saint unable to attend, need a break, …); coordinators answer under
  **Requests**.
- No EMS this Sunday? Dashboard → **No Calling Sewa this week**.
- 🌙/☀️ at the top switches light and dark theme.
